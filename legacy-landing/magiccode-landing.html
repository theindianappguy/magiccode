magiccode

AI-Powered Command Line Interface for Developers

Welcome to magiccode!

magiccode is a powerful CLI tool that combines the convenience of OpenCode with local AI capabilities powered by Ollama. With magiccode, you can seamlessly integrate LLMs into your development workflow directly from your terminal.

1. Prerequisites

Before you can use magiccode with Ollama models, ensure you have the following installed:

  • Ollama: The local LLM inference engine
  • A compatible shell (bash, zsh)
  • Basic terminal skills

2. Install Ollama

Install Ollama by following the instructions for your operating system:

For macOS/Linux:

curl -fsSL https://ollama.com/install.sh | sh

For Windows:

Visit https://ollama.com/download and download the Windows installer.

Note: After installation, restart your terminal or run source ~/.bashrc (or equivalent) for the ollama command to be recognized.

3. Install magiccode

Download and make magiccode executable:

curl -o magiccode https://raw.githubusercontent.com/sanskartiwari/magiccode/main/magiccode
chmod +x magiccode

Alternative: If you already have a copy of the script, place it in your PATH.

4. Get Started with magiccode

Create a new project or work with existing projects:

  • Initialize a new project:
    magiccode init my-project
  • Run your project:
    magiccode run
  • Build your project:
    magiccode build
  • Deploy your project:
    magiccode deploy

5. Using Ollama Models

magiccode integrates with Ollama to provide AI capabilities:

Check available models:

ollama list

Download a model (example: llama3):

ollama pull llama3

Use magiccode with AI:
